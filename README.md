# cputh compiler

Simple joke compiler to compile Charlie Puth source to Python.
Why? Because now you can sing your source code!

`cputh` is a soulful, rhythmic transpiler that converts Charlie Puth lyrics to working Python code. Why use boring keywords like `if` and `while` when you could be demanding `attention` or asking `how_long` your loop has been running?

Inspired by the logic of ArnoldC, but this time with more hair and perfect pitch!

## Mapping

### Imports
- `way_back` -> `from`
- `get_it_now` -> `import`

### Conditionals
- `attention` -> `if`
- `left_out` -> `elif`
- `i_dont_care` -> `else`

### Membership, Logical Operators
- `hold_you_tight` -> `in`
- `no_more` -> `not`

### Loops
- `how_long` -> `while`
- `left_right` -> `for`
- `repeat_it` -> `continue`
- `we_dont_talk_anymore` -> `break`
- `slow_dance` -> `pass`

### Functions and Classes
- `one_call_away` -> `class`
- `say_something` -> `def`
- `done_for_me` -> `return`
- `cheating_on_you` -> `yield`

### Exception Handling
- `dangerously` -> `try`
- `is_it_too_late` -> `except`
- `clean_slate` -> `finally`
- `blame_it_on_me` -> `raise`

### Constants
- `TheWayIAm` -> `True`
- `ForgetAboutYou` -> `False`
- `Maybe` -> `None`

### I/O
- `talk_to_me` -> `print`
- `listen` -> `input`

### Data Structures
- `lightswitch` -> `bool`
- `album` -> `list`
- `playlist` -> `dict`

## Development Status

I made this as a joke, but if something explodes, start an issue.

## Installation & Usage

1. Clone this repository
2. Run binary: `bin/cputh input.cputh output.py`
3. Run the freshly produced Python code: `python3 output.py`
